# Power BI Screenshots & Visual Assets

This directory contains visual previews of the Power BI report pages generated by the automated analytics rendering pipeline (`src/plots.py`).

## Generated Visual Assets:
1. `01_funnel_conversion_view.png` — MQL to Closed Deal Conversion Rates with Wilson 95% Confidence Intervals.
2. `02_speed_survival_view.png` — Kaplan-Meier Survival Curves for Time-To-Close across lead acquisition origins.
3. `03_revenue_view.png` — Post-Signing Revenue per Closed Deal with 95% Bootstrap Confidence Intervals.

To rebuild or refresh these visual assets, run:
```bash
python src/plots.py
```
